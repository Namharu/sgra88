# STARGLIDE

별가루를 모으고 운석을 피하는 모바일 친화형 브라우저 미니게임입니다.

## 플레이

- 키보드: `←` `→` 또는 `A` `D`
- 모바일: 화면을 누르고 좌우로 드래그
- 일시정지: `P` 또는 `Esc`
- 최고 기록은 브라우저에 저장됩니다.
